# DS-1 Command

Death Star live deck for Imperial bots. The public site is:

**https://wheelzbein.github.io/ds1-command/**

## What you will see

- **LIVE DECK** — painted command floor with the 12-bot roster walking their posts
- **HOLOGRAM** — isometric 3D of the same chamber
- **OUTSIDE** — navy sky, nebula, planet, twinkling stars, green dish, Death Squadron ships
- **UNIT SET** — portrait sheet of every bot, including **MEDIC**

Commands: Stand down, Battle stations, Officer mess, Lights out, Report in, Launch TIE-fighters.

## Run locally

```bash
python3 -m http.server 43123
```

Then open http://127.0.0.1:43123/

Add to Home Screen on iPhone or Android to use it like an app.
